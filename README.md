## 🎵 How to Change the Background Song

You can change the song in **3 super easy ways**:

### Method 1: Directly inside the Website (Zero Coding!)
1. Click the floating **Music Player pill** at the bottom-right corner.
2. Click **"Change Song / Upload MP3 🎵"**.
3. You can now:
   - **Upload an MP3/WAV/M4A** file straight from your computer or phone. It saves in browser storage and plays automatically!
   - Pick from **Romantic Presets** (*Golden Romantic Piano, Our Special Song, or Ambient Synthesizers*).
   - Paste a direct **Song Link / URL** and set custom Song Title & Artist.

### Method 2: Permanent Local MP3 File
1. Put any song file into:
   ```
   c:\kishoreproject\Bday\public\music\our-song.mp3
   ```
2. The website will automatically play this file as the default song!

### Method 3: In Data Configuration
Open [`src/data/loveData.js`](file:///c:/kishoreproject/Bday/src/data/loveData.js) and update the `music` block:
```javascript
music: {
  title: "Your Song Name",
  artist: "Singer / Kishore",
  src: "/music/your-song-filename.mp3"
}
```
